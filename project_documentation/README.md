# Sales Data Analysis using SQL

## Project Overview

This project focuses on analyzing sales data using SQL to identify business insights, revenue trends, customer purchasing behavior, and product performance.

## Dataset Information

- Dataset Type: Sales Dataset
- File Format: CSV
- Source: Kaggle
- Total Records: 1000

## Tools Used

- MySQL
- SQL
- Excel
- GitHub

## Project Workflow

1. Database Setup
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Business Analysis
5. Insight Generation
6. Advanced SQL Analysis

## SQL Concepts Used

- Aggregate Functions
- GROUP BY
- ORDER BY
- Subqueries
- Window Functions
- RANK()
- DENSE_RANK()
- ROW_NUMBER()
- LAG()


## Key Business Questions Solved

- Which region generated the highest sales?
- Which product category generated the highest revenue?
- Which sales representative performed best?
- Which customer type contributes more revenue?
- What is the month-over-month sales growth?


## Key Insights

- Returning customers generated higher revenue than new customers.
- Retail sales outperformed online sales.
- Clothing category generated the highest revenue.
- Month-over-month sales growth showed positive trends.
- The North region contributes significantly to overall revenue.
